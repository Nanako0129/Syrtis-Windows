# anim-sand* frame sets

The "Sand shoal" tray animation: `anim-sand{0..3}` (white, dark taskbar) and
`anim-sand{0..3}-light` (black, light taskbar), 144 frames each, 48x48 px,
drawn for 24 fps over a 6 s loop. Level 0 is idle; higher levels fall more sand.

Provenance: original to the Syrtis project (MIT, same licence as this
repository), generated by `scripts/gen_sand_frames.py` in the macOS repository
(Nanako0129/TokenBar-Native). The PNGs are copied byte-for-byte from its
`Sources/Syrtis/Resources/anim-sand*`; do not regenerate them here. Nothing in
this directory is third-party, so it is deliberately not in
`THIRD-PARTY-NOTICES.md`.
